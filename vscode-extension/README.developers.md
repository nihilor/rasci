# vscode-extension Repository (Developer Notes)

Minimal setup for contributors.

## Prerequisites

- Node.js 18+
- npm
- VS Code

## Local Setup

1. Install dependencies:
   - `npm install`
2. Build extension assets:
   - `npm run build`

## Development Loop

1. Open this folder in VS Code.
2. Press F5 to launch an Extension Development Host.
3. In the host window, open a `.rasci` file and run preview commands.
4. For the Markdown integration, open a Markdown file with a ` ```rasci ` block and run `Markdown: Open Preview to the Side`.

## Markdown Preview Integration

The extension hooks into VS Code's built-in Markdown preview:

- `package.json` contributes `"markdown.markdownItPlugins": true` and `"markdown.previewStyles": ["./media/rasci-preview.css"]`.
- `activate()` returns `{ extendMarkdownIt(md) }`. The plugin overrides `md.renderer.rules.fence`, renders fences with the info string `rasci` and passes all others to the previous rule.
- Panel and Markdown preview share `renderFragment()`, so parsing, validation mode and issue blocks behave the same in both.
- The validation mode is read per document via `env.currentDocument`, with the global setting as fallback.
- The rendered block carries `class="code-line"` and `data-line`, which VS Code uses for scroll sync.
- `activate()` returns the plugin even if the core bundle fails to load. The preview then shows an error block instead of breaking.

After changing the plugin or the styles, run `npm run build` and reload the Extension Development Host. The Markdown preview picks up the plugin only after a reload.

## Packaging

- Build and package VSIX:
  - `npm run package`

## Generated Artifacts

- Grammar files in `syntaxes/`
- Runtime core bundle in `dist/rasci-core.cjs` (from `../src/parser.js` and `../src/renderer.html.js`)
- Preview stylesheet in `media/rasci-preview.css`, used by the Markdown preview and the preview panel

`media/rasci-preview.css` is generated by `scripts/build-bundle.mjs`. It concatenates the core stylesheet `../src/rasci-table.css` and the VS Code layer `styles/preview-theme.css`, in this order, so the theme layer wins. Edit those two sources, never the generated file. `media/` and `dist/` are git-ignored but part of the VSIX; `styles/` is a build input and excluded via `.vscodeignore`.

In the Markdown preview the stylesheet applies globally, next to other extensions' styles. Scope new selectors under `.rasci-preview` or use the `rasci-` prefix.

## Common Fixes

- Command not found for preview:
  - Ensure `npm run build` succeeded.
  - Reload the window after reinstalling/updating the extension.
- RASCI block shows as plain code in the Markdown preview:
  - Check that the info string is exactly `rasci`.
  - Reload the window; VS Code loads markdown-it plugins when the Markdown preview starts.
- RASCI table is unstyled:
  - Ensure `media/rasci-preview.css` exists, i.e. `npm run build` ran before packaging.
